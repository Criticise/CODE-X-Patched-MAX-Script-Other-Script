# CODE X Patched MAX Script - Other Script

## English

A small collection of legacy 3ds Max and helper scripts maintained or patched
with AI-assisted code repair. The repository publishes the scripts as they are
used locally, together with the matching release archive.

- Includes MaxScript and Python helper scripts.
- Focuses on practical fixes, compatibility maintenance, and workflow repair
  for older scripts.
- No Resident Evil game assets are included.

Original scripts and their authors retain their respective rights. AI-assisted
repairs in this repository do not claim ownership of the original works.
